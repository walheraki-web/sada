# صدى — Sada

تطبيق Android TV يشغّل محطة صوتية من الإنترنت (تعليق رياضي مثلًا) فوق قناة الريسيفر الحية،
ويزامنها تلقائيًا مع الصورة.

## كيف يعمل

| المهمة | الطريقة |
|---|---|
| سماع صوت القناة | مساعد يعمل بصلاحية shell عبر ADB الريسيفر نفسه (127.0.0.1:5555) يلتقط ما يخرج فعلًا من الريسيفر (Echo reference، أو Remote submix)؛ «فحص الريسيفر» يجد الأسلوب الذي يحمل صوت القناة. بدائل: التقاط النظام (MediaProjection) أو الميكروفون. |
| اللوحة | نافذة فوق القناة ترسمها خدمة إمكانية الوصول، فيبقى تطبيق التلفاز في المقدمة ويستمر بالعمل. تُفتح بالأحمر مرتين. ▲▼ تنقّل، ◂ ▸ تغيير، OK تنفيذ. |
| قياس الفرق | بصمة onset في 24 نطاقًا + ارتباط متقاطع بالـ FFT، مدى بحث يتّسع تدريجيًا حتى +60 ث / −20 ث، ولا تُقبل النتيجة إلا إذا أكّدتها نافذة مستقلة. |
| المحطة متأخرة | يردّ جزءًا من تأخيرها أولًا، وإلا **يوقف القناة مؤقتًا** بزر الوسائط (85) ثم يستأنفها بعد المدة المطلوبة بالضبط (timeshift الريسيفر نفسه)، ويتحقق أن صوت القناة انقطع فعلًا أثناء الإيقاف. |
| المحطة مبكرة | يؤخّرها بخط تأخير دقيق للإطار، بلا نقرات (صمت عند الزيادة، تلاشٍ متقاطع عند النقصان). |
| بعد التصحيح | قياس تحقّق يقصّ الفرق المتبقي، ومراقبة كل 3 دقائق، وتعويض فوري لأي توقف مؤقت في المحطة. |
| كتم القناة | المحطة تُشغَّل على مسار المنبّه، ويُخفَض مستوى صوت الوسائط (صوت القناة) إلى صفر، ويُتحقق من النتيجة. |

## البناء

يُبنى تلقائيًا عبر GitHub Actions عند كل رفع، وتُشغَّل اختبارات محرك المزامنة وخط التأخير قبل البناء.
آخر APK من فرع main يُنشر في إصدار `latest`.

## أول تشغيل على الريسيفر

1. فعّل «تصحيح ADB عبر الشبكة» من خيارات المطوّر (أو `adb tcpip 5555` مرة من الكمبيوتر).
2. افتح صدى، أضف محطة أو استورد ملف m3u/cfg.
3. فعّل «Sada» من الإعدادات ▸ إمكانية الوصول.
4. اضغط «فحص الريسيفر» والقناة تعمل بصوت؛ عند «السماح بالتصحيح» اختر «السماح دائمًا».
5. على القناة: الأحمر مرتين ▸ تشغيل. المزامنة التلقائية تعمل وحدها.
6. «تجربة تأخير الصورة» تتأكد أن الإيقاف المؤقت يعمل؛ «تسجيل صوت القناة وسماعه» يتأكد أن الالتقاط يحمل صوت القناة.
